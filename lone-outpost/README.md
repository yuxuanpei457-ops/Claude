# 孤哨行动 · Operation Lone Outpost

原创的手机网页战术射击游戏（搜打撤玩法），使用 three.js 开发，单文件，无需安装。

- `standalone.html`：直接用浏览器打开即可游玩（手机请横屏）
- `index.html`：发布为 Claude Artifact 用的版本（不含 doctype 外壳）

## 玩法
从南侧潜入补给站，搜索物资、清除守军，15:00 内抵达北侧撤离点 A 或 B 并停留 8 秒。阵亡或超时，物资全部丢失。

## 硬核要素
- 后坐力需要手动压枪，腰射扩散随移动、跳跃、连射增大，开镜和蹲下更稳
- 战术换弹（弹匣有余弹时可多装 1 发进枪膛），空仓换弹时间更长
- 伤害随距离衰减，有爆头倍率；敌我都有护甲
- 中弹可能流血，需要用绷带或医疗包处理；治疗和搜索都需要时间
- 敌人会听枪声包抄、搜索，有反应时间和点射；远处枪声按声速延迟传来
- 硬核难度：没有准星，弹药只能估算
